# Direction contract — Registered archive

Mode: Experience

## World

An editorial project archive with the firm layout of a printed catalogue and one restrained print-registration gesture. The user-pinned warm paper, near-black, and vivid orange palette, fine rules, numbered index, oversized serif, and compact technical labels govern the system. A subtle offset between two orange/black planes signals a project change. It never becomes a paper-grain filter, noisy texture, or a competing palette.

## First viewport

A slim horizontal metadata strip establishes identity and location. Below it, a persistent left column carries Jishnu's introduction and numbered project index; the right side is a generous project canvas. Revalo leads. Its canvas is a project-specific field study of the valuation inputs and vehicle classes described in the resume, rendered as editorial information art rather than an invented app screenshot. The composition must read at a glance as a project archive, not a centered landing-page hero.

## Visitor path

The visitor scans the professional scope and project list, explores the active project composition, then opens a case study. A compact experience preview follows the archive, then skills and a clear opportunity contact prompt. The same navigation connects the full work, experience, about, and contact routes.

## Signature interaction

Hovering or keyboard-focusing a desktop project row updates the canvas. Selecting a project uses one brief orange registration reveal, then holds the selected project facts in the canvas. On touch screens, a dedicated tap target selects the preview and a visible case-study link opens the project. Reduced-motion preferences disable the reveal while keeping all content and controls available.

## Cross-surface reach

Numbered folio labels, thin black rules, paper surfaces, serif display type, monospaced metadata, and restrained orange carry through the archive, case studies, experience chronology, about page, and contact route. Project rows remain data-driven and reusable.

## Honest risk

Project screenshots and several demo/repository URLs are not present in the supplied materials. Project canvases must remain clearly authored editorial studies based on verified facts; they must never mimic product UIs or be labeled as screenshots. Actual screenshots can replace these studies when supplied.
